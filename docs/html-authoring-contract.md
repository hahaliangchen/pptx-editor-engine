# HTML 作者规范 v0：1280 × 720

状态：目标规范。已接入本地产品转换接口，尚未部署线上。只保存 PPTX，JSON 与 HTML 是按需转换的工作视图。本文中的渐变、阴影、裁剪和完整测量元数据仍是目标能力，不代表全部已实现；实际范围见 [design-layer.md](design-layer.md)。Anthropic 仅用于 HTML 作者格式与审美参考，不采用其完整 HTML→PPTX 流程。

## 页面与设计

- 每页一个 HTML 文档，画布固定 1280 × 720 CSS px，body margin 为 0，全局 `box-sizing: border-box`。
- 设计可以使用 flex、grid、绝对定位；浏览器排版结束后转为绝对坐标。导入后不再自动布局、自动缩字或调整构图。
- 模板是参考与可复用素材来源。只保留明确锁定的品牌元素，不强制套槽位；空模板允许自由设计。
- 页数随内容规划，不固定为 5 页。
- 所有文字放在 h1–h6、p、li 等明确的文本容器中；容器内可用 span、strong、em 混排。禁止在布局容器下放置未标识的裸文本。
- 可编辑文字不得嵌进整页截图。图标、插画、总结图可以作为独立 SVG/位图资产；不能用生僻 Unicode 字符充当图标。
- 每个需要编辑或定位的节点使用唯一 `data-id`，便于错误定位、资产关联和后续更新。

## 首版可映射范围

| 内容 | 约束 |
|---|---|
| 背景 | 纯色、经验证的线性渐变 |
| 边框 | 四边相同的实线颜色与宽度 |
| 圆角 | 四角相同的圆形半径；需要精确映射到 shape adjustment |
| 阴影 | 单个外阴影，spread 为 0；模糊值经过映射验证 |
| 透明度 | 叶节点的可映射填充/线条/图片透明度；不将父容器整体合成透明度冒充子元素透明度 |
| 文字 | 字体、字号、粗斜体、颜色、字距、行高、段距、对齐与内边距；以实际测量行和片段为准 |
| 图片 | PNG/JPEG，明确尺寸；支持已验证的 contain/cover 和定位映射 |
| SVG | 独立资产，保留 SVG 原稿与可靠的显示资产；首版不承诺任意路径均可作为原生 PPT 路径编辑 |

首版遇到 filter、backdrop-filter、混合模式、复杂 mask、动画、伪元素内容、多重阴影、不等角圆角、复杂 transform/嵌套 stacking context 等未支持表达时，返回定位明确的错误，由作者重写或显式转成单独资产。不能静默删样式，也不能擅自把整页截图。

浏览器可以用 CSS 流式排版；PPT 导入只使用冻结后的结果。可允许的 CSS 属性最终以转换器版本化的能力清单为准，本文不是“所有浏览器样式均可转换”的承诺。

## 测量输出必须包含

- schema 版本、画布宽高、单位 `css-px`、HTML 源哈希、资源哈希、浏览器版本、字体清单、目标文档版本。
- 稳定 DOM 节点 ID、对象归属、背景框、文字内容框、父子关系和实际绘制顺序。
- 文本原文、段落、富文本片段、浏览器实际断行、每行位置、字体与字号、行高、基线所需信息、内边距和对齐。
- 图形填充、边框、圆角、阴影；图片 URL/内容哈希、裁剪、资产引用。
- 未支持特性、缺字体、缺资产、文字裁切、越界的诊断列表。禁止通过 clipping 隐藏问题后报告成功。

测量输出是内部场景描述，之后还须通过原生导入桥建立编辑器对象和 OOXML，不能直接替换渲染 JSON 后宣称导出已完成。

## 字体与资源

- 等待字体与图片完成加载，并检查指定字体确实存在；`document.fonts.ready` 本身不能证明没有字体回退。
- 浏览器测量、编辑器渲染使用相同字体文件。PPTX 中写入明确的中英文字体；外部 Office 环境缺字体仍可能改变排版，需要字体部署或具备许可的嵌入策略。
- 图片加载失败、SVG 缺资源、文字替换成缺字方框时返回错误，不生成占位成品。
- 转换页面不执行作者脚本；资产从受控清单加载。不要把任意网页导航作为 PPT 作者输入。

## 校验与修复

1. 检查画布、字体、资产、可映射特性和唯一节点 ID。
2. 同时检查页面和各文本容器的可见区域、实际文字矩形与裁切；只看 body 的 scrollHeight 不足以证明文字完整。
3. 区分设计允许的重叠（文字覆盖背景）和异常遮挡；保留背景/文字的关联，不能把正常卡片判成问题。
4. 将具体节点、原因、测量值返回作者修复；不自行改字号、挪位置、补模板槽位。
5. 对照 HTML、编辑器、导出重开的页面渲染，确认完整性与一致性，再进行美观度检查。
6. 全部页面均需检查。页面多时分批处理并记录覆盖范围；内容缺失、空占位、图标缺失不等同于“没有越界”。

## 模板转换交接

先用一个当前标准模板完成链路，再记录品牌规则、固定元素、可复用组件、素材角色（参考图/必须保留/按主题重画）、字体和资产清单。不要为兼容旧关键字额外建立填槽逻辑。

模板里的示例总结图应标注为构图参考；只有明确要求保留的资产才原样带入。AI 需根据主题重新组织图中内容，避免把参考图当作不可修改的死图。
