# 模板占位符约定

一份模板就是一份普通的 .pptx：每种页面一页，要填内容的地方写成 `{{关键字}}`。
引擎（`src/api/template.ts` 的 `inferTemplate`）只看页面上的关键字，就能认出每页的角色和能填哪些字段；
`get_template` 把这些告诉 Agent，`build_deck` 按它一次生成整份稿子。不需要另外的说明文件。

本文是模板生成页（用户上传 PPT → 选每页的角色 → 自动写入占位符）要遵守的约定，也是引擎目前的实际行为。

## 页面组成

模板是 **4 页必选 + 1 页可选**，顺序固定：

| 顺序 | 角色 | 是否必须 | 用途 |
|---|---|---|---|
| 1 | 封面 `cover` | 必须 | 标题、副标题、作者、日期 |
| 2 | 目录 `toc` | 必须 | 章节列表 |
| 3 | 章节页 `section` | 可选 | 每章开头的过渡页 |
| 4 | 内容页 `content` | 必须 | 标题 + 一块放内容的区域，引擎在里面排文字、要点、卡片、图表、表格 |
| 5 | 结束页 `end` | 必须 | 致谢、联系方式 |

- 每种角色只放一页。引擎对同一种角色只取第一页，多出来的会被忽略。
- 没有章节页时，`build_deck` 照常生成，只是没有章节过渡页；Agent 要用 `section` 时会收到
  `模板没有 "section" 这种页面，可用的有：cover、toc、content、end`，再改用现有页面。

## 关键字

写法：两对花括号，里面只有大写字母、数字和下划线，例如 `{{PAGE_TITLE}}`。

### 每种角色的关键字

**封面**

| 关键字 | 必须 | 填入的字段 |
|---|---|---|
| `{{TITLE}}` | 必须 | `title` |
| `{{SUBTITLE}}` | 可选 | `subtitle` |
| `{{AUTHOR}}` | 可选 | `author` |
| `{{DATE}}` | 可选 | `date` |

**目录**

| 关键字 | 必须 | 说明 |
|---|---|---|
| `{{TOC_ITEM_1_TITLE}}` … `{{TOC_ITEM_N_TITLE}}` | 必须，至少 1 项 | 第 n 项的章节名 |
| `{{TOC_ITEM_n_DESC}}` | 可选 | 第 n 项的一句话说明 |

**章节页（可选）**

| 关键字 | 必须 | 填入的字段 |
|---|---|---|
| `{{CHAPTER_TITLE}}` | 必须 | `title` |
| `{{CHAPTER_NUM}}` | 可选 | 引擎自动填：第几章（01、02……），也可以由 `number` 指定 |
| `{{CHAPTER_DESC}}` | 可选 | `desc` |
| `{{CHAPTER_SUBTITLE}}` | 可选 | `subtitle` |

**内容页**

| 关键字 | 必须 | 说明 |
|---|---|---|
| `{{PAGE_TITLE}}` | 必须 | `title` |
| `{{CONTENT_AREA}}` | 必须 | 标出放内容的区域，见下文 |

**结束页**

| 关键字 | 必须 | 填入的字段 |
|---|---|---|
| `{{THANK_YOU}}` | 必须 | `title`（例如"谢谢"） |
| `{{ENDING_SUBTITLE}}` | 可选 | `subtitle` |
| `{{CLOSING_MESSAGE}}` | 可选 | `message` |
| `{{CONTACT_INFO}}` | 可选 | `contact` |

### 任何页面都可以用的关键字

| 关键字 | 说明 |
|---|---|
| `{{PAGE_NUM}}` | 引擎自动填：这一页是第几页 |
| `{{TOTAL_PAGES}}` | 引擎自动填：总页数，常写成 `{{PAGE_NUM}} / {{TOTAL_PAGES}}` |
| `{{SECTION_NUM}}` | 引擎自动填：当前是第几章（01、02……） |
| `{{LOGO}}`、`{{LOGO_...}}` | 只做标记，不作为字段；写着它的文本框在生成时被删掉 |

上面是每种角色的基本关键字。现有模板里一共用到 142 个关键字，按"通用字段""同义写法""固定版式字段"整理在
[template-keywords.md](template-keywords.md)。模板生成页给用户选的，是基本关键字加上那里的"通用字段"
（如封面的 `{{INSTITUTION}}`、`{{PRESENTER}}`，内容页的 `{{SOURCE}}`、`{{KEY_MESSAGE}}`）。
引擎接受任何关键字（`{{INSTITUTION}}` 会成为字段 `institution`），但 Agent 只看得到字段名，
所以新加的关键字要起一个一看就懂的名字；同一个意思用清单里建议的那个写法。

### 引擎怎么判断页面角色

按下面的顺序，页面上第一条符合的就是它的角色：

1. 有 `TOC_ITEM_` 开头的关键字 → 目录
2. 有 `{{CONTENT_AREA}}` → 内容页
3. 有 `CHAPTER_` 开头的关键字或 `{{SECTION_NAME}}` → 章节页
4. 有 `{{THANK_YOU}}` → 结束页
5. 有 `{{TITLE}}` → 封面

所以**角色标记要放对页**：`TOC_ITEM_*` 只放目录页，`CONTENT_AREA` 只放内容页，封面上不放 `CHAPTER_*`
（否则封面会被当成章节页）。内容页上放 `{{CHAPTER_NUM}}`、`{{SECTION_NAME}}`，结束页上放 `{{DATE}}` 都没问题，
因为内容页先于章节页判断，`DATE` 不是角色标记。

## 写占位符的规则

### 1. 占位符必须放在"纯文本框"里

引擎只读文本框里的关键字。**有填充色或边框的形状**（比如一个带底色的圆角矩形，里面写着 `{{TOC_ITEM_1_TITLE}}`）
算作形状，里面的关键字会被忽略。

做法：底色块和文字分开，色块留着当装饰，在它上面单独放一个无填充、无边框的文本框写关键字。

### 2. 一个文本框只放一个要填的关键字

可以带固定的字或自动关键字，例如 `PART {{CHAPTER_NUM}}`、`{{PAGE_NUM}} / {{TOTAL_PAGES}}`。
不要在一个框里放两个要填的字段（如 `{{TITLE}}{{SUBTITLE}}`），它们会挤在同一个框里，字号也只能一起缩放。
引擎写入文字时沿用框里开头文字的字体、字号和颜色，所以占位符的样式就是最终文字的样式
（文字放不下时，引擎会在框内缩小字号）。文本框的大小要按真实内容留够，不要只按占位符本身的长度。

### 3. 可选字段没有内容时，整个文本框会被删掉

例如 Agent 没给 `subtitle`，`{{SUBTITLE}}` 所在的框就不出现。所以可选字段要放在单独的框里，
不要和必须显示的文字放在一起。

### 4. 示例文字要清掉

不含关键字的文字（品牌口号、示例公司名等）会原样留在每一页上，Agent 只能用 `replace` 逐条替换。
模板生成页在写入占位符时，要把示例文字删掉或换成关键字；要保留的固定文字（如"目录"二字、公司名）明确留下。

### 5. 装饰保留

背景、图片、色块、线条、logo 都不动。只处理文本框，以及内容区里原有的表格、图表和示例图片。

## 目录页

目录的每一项由这些对象组成，按图层顺序（从下到上）排列：

```
"目录" 标题   ← 必须有，且在第一项之前
[序号 01] [装饰]  {{TOC_ITEM_1_TITLE}}  {{TOC_ITEM_1_DESC}}
[序号 02] [装饰]  {{TOC_ITEM_2_TITLE}}  {{TOC_ITEM_2_DESC}}
...
```

- 引擎从图层顺序上划分每一项：上一项的最后一个对象之后，到这一项的标题（和紧跟它的说明）为止，都属于这一项。
  Agent 给的项数少于模板时，多出的项连同它的序号和装饰一起删掉，留下的项整体往中间挪。
- **"目录"这类标题文字必须在第一项之前**。没有它时，第一项之前的所有对象（包括整页的背景装饰）都会被算进第一项，
  挪动时会跟着移动。
- 每一项的对象在图层上要连续，标题在说明之前；说明是紧跟在标题后面的那个文本框。
- 项数就是 Agent 最多能写的章节数，建议 5 到 6 项。超过时 `build_deck` 会报"目录页最多 N 项"。
- 序号写成固定数字（`01`、`02`），不用关键字。

## 内容页

`{{CONTENT_AREA}}` 标出内容放在哪里，有两种写法：

1. **推荐**：画一个矩形框（可以是虚线、无填充）表示内容区的范围，在框中间放一个写着 `{{CONTENT_AREA}}` 的文本框。
   引擎取包住这个文本框的最大形状作为内容区（不能是整页大小的形状）。
2. 只放一个 `{{CONTENT_AREA}}` 文本框：引擎把标题下方、左右边距以内、页脚以上的区域当作内容区。

生成时，这个框和文字都会被删掉，内容排在它的位置上。内容区要足够大，至少放得下两块左右并排的内容。

## 模板生成页的流程

1. 用户上传 .pptx，在编辑器里打开。
2. 用户（或 AI 建议后由用户确认）给页面指定角色：封面、目录、内容页、结束页各一页，章节页可选；其余页删除，按上表顺序排列。
3. 对每一页：
   - AI 看页面结构和截图，建议哪个文本框对应哪个关键字（例如字号最大的框是标题）；
   - 对应上的文本框，把文字换成关键字，位置和样式不动；
   - 对应不上的示例文字删掉；
   - 这个角色还缺的必须关键字，新加一个文本框，由用户拖到合适的位置；
   - 内容页画出内容区；目录页确认项数和"目录"标题。
4. 保存前检查（见下节），通过后保存为模板，并生成 `design_spec.md`。

## 保存前的检查

| 检查 | 不通过时 |
|---|---|
| 4 种必选角色各有且只有一页，章节页最多一页 | 提示缺哪种角色或哪种重复 |
| 每页有它角色的必须关键字，且角色标记没有放错页（见判断顺序） | 指出哪页、缺什么或放错了什么 |
| 关键字都在纯文本框里（不在有填充或边框的形状里） | 指出那个形状 |
| 关键字在 [template-keywords.md](template-keywords.md) 的清单里，且用的是建议的写法 | 指出未知的或该统一的关键字 |
| 目录页的"目录"标题在第一项之前，各项编号从 1 连续 | 指出问题 |
| `get_template` 认出的角色和用户标注的一致 | 显示引擎认出的结果 |
| 用一份示例内容跑 `build_deck`，再跑 `check_layout` | 给用户看生成结果和版面问题 |

示例内容至少要覆盖：带副标题的封面、5 项目录、（有章节页时）一个章节页、
一页两块并排的内容页、一页带图表的内容页、结束页。
